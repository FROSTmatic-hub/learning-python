# What is Formatted String?
- Formatted String lets you insert variables of different data types directly into your string
- It makes writing code simple and easier to understand.
- We can write it using `f"` and variable names are written inside curly brackets `{}`. 
```python
user_name = "Shaafi"
user_age = 23
user_info = f"Hello {user_name}. You are {user_age} years old.
```
