# What are Augmented Assignment Operators?
- Augmented Assignment Operators are basically shortcut way of updating the value of an existing variable. 
```python
user_age = 19
# we want to add 1 to it
user_age = user_age + 1
# Or we can use augmented operator to easily to this
user_age += 1
```

>It works with all the other operators such as +, -, *, /


> [!NOTE] IMPORTANT
> The variable must already exist to use augmented assignment operators
