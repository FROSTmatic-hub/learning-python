# What is a Data Type?
- Data types tell python what kind of value something represents. 
- Python has different data types, that helps distinguish different values.

# What are the eight Fundamental Data Types?
- The eight fundamental data types are:
```python
int  #integer
float #decimal value
bool #true or false values
list #represents different data types in list format
dict #represents different data types  in key-value pairs
set  #represents unique data types in set format
tuple #represents different data types in tuple format
str  #represents character values
```
