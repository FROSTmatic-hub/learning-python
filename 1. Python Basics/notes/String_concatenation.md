# What is String Concatenation?
- String Concatenation is used to join two or more strings together using `+` sign.
```python
first_name = "shaafi"
last_name = "khan"
full_name = first_name + last_name
```

> [!IMPORTANT] 
> We cannot concatenate str with int or float, etc. It will give us an TypeError

```python
a = 5
b = "Hi"
c = a + b
#will give an TypeError
```
