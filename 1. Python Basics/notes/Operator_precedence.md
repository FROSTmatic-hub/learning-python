# What is Operator Precedence?
- Operator Precedence is the order that python follows while evaluating operators in an expression.
# Order Precedence?

| 1.  | ()   | Parenthesis                 |
| --- | ---- | --------------------------- |
| 2.  | **   | Power off                   |
| 3.  | *, / | Multiplication and Division |
| 4.  | +, - | Addition and Substraction   |
