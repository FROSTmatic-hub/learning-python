# What are the rules for naming variables?
1. **Use snake_case for multiple words**
```python
my_name = "shaafi"
last_number = 9
```
2. **Don't start with a number**
```python
1number = 9
#This is wrong practice
number = 9
```
3. **Variables are case-sensitive
```python
Age = 19
age = 19
#Both Age and age are different
```
4. **Letters, numbers and __ are allowed**
```python
user1 = "Me"
user_age = 21
```
5. **Do not use keywords as variable names**
```python
print
while
pass
for
if
# These are all keywords and should not be used as variable names
