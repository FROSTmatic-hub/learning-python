# What is `bool`
- A Boolean or `bool()` is a [[Data types]] that only represents two values:
	- `True`
	- `False`
> A data type can be converted into Boolean using `bool()`
# Examples of Boolean
```python
bool(1) # This means True
bool(0) # This means False
bool("hello) # Any non-empty string of data type is True
bool("") # THis is False
```
